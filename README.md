# Redline MD redesign (concept)

Design concept for the Foundey design challenge. Vite, React, TypeScript, Tailwind v4, Framer Motion and Lenis.

```bash
npm install
npm run dev
```

- Design rationale: [DESIGN-NOTES.md](DESIGN-NOTES.md)
- Images to generate and where they go: [IMAGE-MAP.md](IMAGE-MAP.md)

Deploy: Vercel, Vite preset (build `npm run build`, output `dist`).
